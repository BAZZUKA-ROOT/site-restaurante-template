# 🍽️ Site Restaurante — Template HTML/CSS/JS

Template responsivo para restaurante ou estabelecimento alimentício — menu, galeria, reservas e integração com WhatsApp. Zero dependências, hospedagem estática.

![Language](https://img.shields.io/badge/Stack-HTML%20%7C%20CSS%20%7C%20JS-orange) ![License](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue)

---

## 🎯 O que tem

- Layout moderno com hero e menu de pratos
- Galeria de fotos do ambiente
- Seção de horários e localização
- Botão de pedido pelo WhatsApp
- Dark mode automático via `prefers-color-scheme`
- Animações suaves com CSS puro
- Mobile-first, sem frameworks

## ⚙️ Como usar

1. Abra `index.html` e troque nome, fotos e número do WhatsApp
2. Hospede em qualquer servidor estático (GitHub Pages, Netlify, Cloudflare Pages)
3. Pronto — zero configuração de backend
